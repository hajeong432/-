# ☔ 스마트 우산 알리미 (Umbrella Alarm)

실시간 날씨 정보를 확인하여 외출 전 우산을 챙겨야 할지 결정해 주는 똑똑한 파이썬 프로그램입니다.

---

### ✨ 주요 기능
* **실시간 상태 분석**: 현재 기온과 강수 확률을 분석합니다.
* **맞춤형 추천**: 
  * 🌧️ 비가 올 것 같으면 **'장우산'** 추천
  * 🌥️ 소나기 가능성이 있으면 **'접이식 우산'** 추천
  * ☀️ 맑으면 **'가벼운 외출'** 추천

---

### 🚀 실행 방법
터미널에 아래 명령어를 입력하세요:
`python main.py`
